# 자연 이미지 반복 실험 — 실행 안내와 해석 범위

## 현재 전달 단계

v0.4.0에서는 이 고정 프로토콜의 **CIFAR-10 본 실험 반환 결과를 관측·통합했다.** 교사 3개와 후보 30개, 총 33개 모델이 모두 최종 평가와 Vela 컴파일까지 완료됐고 오류는 0건이다. 결과와 해석은 [NATURAL_RESULTS.md](NATURAL_RESULTS.md)에 있으며, 이 문서는 사전에 고정한 조건과 실행 규약을 보존한다. 자연 이미지 본 실험의 공개 집계는 `docs/results/`를 기준으로 한다.

## v0.3.1 데이터 준비 수정

반환된 v0.3.0 실행에서는 패키지 설치와 import가 성공했고, `prepare-cifar`가 900.33초 후 종료 코드 124로 중단됐다. 해당 로그가 비어 있으므로 다운로드의 DNS/연결/전송과 파일 처리 중 어느 부분이 지연됐는지 확정하지 않는다. 새 학습 결과는 없었다.

새 전송기는 주소별 전체 제한 180초, 소켓 제한 15초, 5초 간격 전송량을 기록한다. TensorFlow에 기록된 CIFAR mirror의 HTTPS 전송 경로를 먼저 사용하고 Toronto 주소로도 시도한다. 어느 경로든 170,052,171 bytes와 기존 SHA-256이 모두 맞아야 승인한다. 실제 원격 다운로드의 성공은 실행 환경에 달려 있으며 아직 이 검토 환경에서 확인되지 않았다.

이전 부분 다운로드는 삭제하거나 데이터로 재사용하지 않는다. 새 시도는 별도 경로를 쓰므로 이전 중단 파일 때문에 즉시 실패하지 않는다. `.npz`와 메타데이터는 임시 디렉터리에서 완료한 후에만 정식 준비 디렉터리가 된다. 실패한 임시 파일은 따로 남고 다음 시도를 막지 않는다. 최종 셀은 최신 로그로 ZIP을 다시 생성하며, `downloads/` 진단만 포함하고 원시 CIFAR 이미지는 포함하지 않는다.

## 연구 질문과 비교군

같은 지원 제약에서 구간 단위 대체가 단순 연산자 대체 또는 작은 학생 모델보다
어떤 회복 학습 예산에서 유리하거나 불리한지를 비교한다. 방법의 우위를 전제하지 않는다.
공개 사전학습 고객 모델이 아니라 **직접 작성한 소형 RegionCNN**의 통제 실험이다.

다섯 고정 방법은 원형 추가 학습, 연산자별 대체, 두 구간 대체, 한 구간 대체,
소형 학생 모델이다. 새 구간의 초기화는 두 구간 대체와 소형 학생 사이에서 일치시키고,
소형 학생의 stem/head는 새로 초기화한다. 기존 가중치 유지의 효과를 비교하기 위한
통제이며, 이전 digits 예비 실험의 초기화나 결과를 소급 변경하지 않는다.

## 사전에 고정한 조건

| 항목 | 본 실험 설정 |
|---|---|
| 입력 | 공식 CIFAR-10 binary, RGB 32×32, `uint8 / 255`, 증강 없음 |
| 학습·검증 | 공식 학습 부분에서 10,000장 / 2,000장, 클래스별 1,000 / 200장 |
| 시험 | 공식 시험 이미지 10,000장 유지; 세 시드에서 같은 이미지 사용 |
| 분할 기준 | 시드 20260917, 정확한 이미지 중복 제거, 원본 인덱스 보존 |
| 모델·반복 | RegionCNN 폭 16, 초기화 시드 17·29·43 |
| 교사 학습 | 시드당 3,000 업데이트, 배치 32, 초기 학습률 0.04 |
| 회복 예산 | 원형의 80·320 업데이트 상당 MAC 대리지표, 각 예산은 같은 교사에서 독립 시작 |
| 학습 손실 | CE 0.5 + KL 0.5 (T=2, T² 배율) + 최종 구간 특징 MSE 0.1 |
| 선택 | 검증 정확도, 동률이면 먼저 확인한 체크포인트 유지 |
| 선택 모델 | 교사 3개 + 5방법×2예산×3시드 = 33개 |
| 보정 | 시드마다 학습 분할에서 128장, 해당 시드의 모든 방법에 동일 표본 |
| 외부 변환 | TensorFlow 2.20.0, Vela 5.1.0, `ethos-u55-256` |
| 평가 | PyTorch FP32 CPU, Vela 이전 TFLite BUILTIN_REF CPU |

전체 공식 학습 50,000장을 사용한 벤치마크가 아니다. 원형 구조·증강·교사 학습량을
성능을 본 뒤 자동 변경하지 않는다. 충분한 수렴이나 최신 최상위 성능을 보장하지 않는다.
고정 설정 파일은 `configs/cifar10_natural_v1.json`이고 내용 해시가 모든 결과에 저장된다.

### 데이터 검사

다운로드 파일은 SHA-256, MD5와 파일 크기를 검증한다. pickle을 읽지 않고 필요한
고정 길이 binary member만 파싱한다. archive.extractall로 외부 자료를 풀지 않는다.
공식 시험 이미지와 정확히 같은 학습 이미지, 학습 중 라벨이 충돌하는 이미지 그룹은 제외한다.
학습/검증 사이에도 동일 이미지 해시가 중복되지 않도록 고른다. 원본 시험 이미지는 유지한다.
이것은 near-duplicate 제거 또는 데이터셋의 모든 오염을 검증했다는 뜻이 아니다.

## 실행 순서

1. 새 CPU 런타임의 패키지·컴파일러를 준비하고 버전을 기록한다.
2. 검증된 CIFAR를 준비하고 원본 분할 인덱스를 기록한다.
3. **학습하지 않은 RGB 32×32 원형**을 먼저 변환·컴파일해 실제 후보 구간이 CPU에 남는지 확인한다.
   이 단계는 구조적 검사이며 정확도 근거가 아니다. 조건이 없으면 비싼 학습을 시작하지 않는다.
4. 시드별 교사와 모든 예산·방법의 회복 학습을 수행한다. 훈련 중은 검증셋만 평가한다.
5. 선택된 **33개 모델을 모두 저장·해시 고정한 다음에만 시험셋 평가**를 시작한다.
6. 선택된 각 모델에서 PyTorch↔TensorFlow 및 FP32 TFLite 수치 대조, 양자화와 CPU 참조 평가,
   Vela 컴파일을 수행한다. 학습 전 구조 검사만으로 학습 후 컴파일을 생략하지 않는다.
7. 기록 33개와 각 분모·시험 인덱스·원시 예측을 검산하고, 고정 비교의 시드별 차이를 집계한다.

교사는 시드마다 한 번 학습해서 두 회복 예산에 공유한다. 작은 학생 모델도 이 교사의
증류 정보를 사용한다. 교사 학습 비용이 없어졌거나 학생에게 무료인 정보라고 표현하지 않는다.

## 예산의 의미

성공한 학습 실행의 `(3×학생 Conv/Linear MAC + 교사 Conv/Linear MAC)×이미지 수`를
누적한다. 작은 모델은 같은 상한으로 더 많은 업데이트를 할 수 있다. 정규화·원소 연산·메모리·
검증·변환·실제 역전파 커널 비용은 이 대리지표에서 빠지며 제외 목록과 실제 경과 시간을 저장한다.
실제 벽시계 시간과 모든 하드웨어 비용이 공정하게 동일하다는 주장은 하지 않는다.

교사 학습은 별도 기록이고 실패·중단된 시도도 보존한다. 실패한 업데이트의 정확한 연산량은
완전히 계측하지 못하므로 모든 시도의 총 비용 우위로 해석하지 않는다. 결과를 좋게 만드는
추가 후보 탐색이나 검증셋 밖의 선택 규칙은 실행기에 없다.

## 결과 해석

- 양자화 정확도는 컴파일 전 TFLite의 CPU 참조 실행이다. Vela의 ethos-u 바이너리를 CPU로 실행하지 않는다.
- CPU 잔류 연산·NPU 실행 구간 수는 컴파일 관측이고 지연·전력 실측이 아니다. 모빌린트 SDK가 아니다.
- INT8 입출력 모델 내부에도 다른 자료형이 남을 수 있어 변환 후 그래프를 기록한다.
  이전 digits의 내부 INT8 관측을 새 CIFAR 모델에 자동 적용하지 않는다.
- 주 비교는 두 구간 대체에서 연산자별 대체/소형 학생의 정확도를 뺀 값이다.
  같은 이미지의 정답 여부를 시드 안에서 짝지어 비교하고, 세 시드 차이의 평균·표준편차를 별도로 표시한다.
- 세 번 사용한 같은 시험셋을 30,000개의 독립 표본으로 합치지 않는다.
  Wald 구간은 기술적 요약이며 다중비교 보정·동등성·우위를 입증하는 판정이 아니다.
- 누락·실패 결과는 0으로 채우지 않고 부분 완료로 표시한다. 승자를 자동 선택하지 않는다.

## 실행

Linux/Colab CPU 환경에서 저장소 루트 기준으로 다음 실행기를 사용한다. API 키나 GPU는 필요 없다.

```bash
python tools/run_natural_study.py --install --session runs/natural-study
```

실행기는 의존성·CIFAR-10 준비·반복 학습·TFLite 변환·Vela 컴파일을 단계별 로그로 남긴다. 중단되면 완료한 모델 작업은 보존하며, 같은 런타임에서 조건과 해시가 일치하는 완료 작업만 재사용한다. 원시 CIFAR 이미지는 결과 ZIP에서 제외한다. Windows 네이티브는 검증 대상이 아니다.
