Question

지원되지 않는 연산을 없애면서 정확도와 크기를 어떻게 지킬까?

Operator-wise

미지원 연산만 교체. 정확도는 상대적으로 높지만 모델 크기는 유지됩니다.

Region-wise

연결된 구간 전체를 작은 block으로 교체. host op 0과 파라미터 감소를 함께 얻었습니다.

Small student

Region-wise와 같은 크기를 새로 학습한 baseline. 기존 가중치 재사용의 가치를 확인하기 위한 대조군입니다.

핵심 해석: Region-wise가 항상 우수한 것은 아닙니다. 정확도는 Operator-wise가 높았고, Region-wise의 장점은 더 작은 모델·낮은 Vela 추정 비용과 낮은 적응 예산에서의 빠른 회복이었습니다.
