Methods

Fallback 제거 자체는 한 가지 방법만의 장점이 아니었습니다

Operator-wise

지원되지 않는 연산만 교체. host op 0, 모델 크기는 유지.

Region-wise

연결 구간을 더 작은 block으로 교체. host op 0, 파라미터 26.22% 감소.

Small student

Region-wise와 같은 크기를 새로 학습한 강한 baseline. host op 0.
